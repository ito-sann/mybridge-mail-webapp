CSVからメール作成

名刺データを読み込んで、相手ごとの挨拶メールを作れます。

CSVを入れるだけで、見込み業務の分類、メール文面、重複チェック、送信対象の確認まで同じ画面で進められます。

1. 読み込む myBridgeのCSVを選択
2. 確認する 分類・メモ・文面を調整
3. 開く Gmail作成画面で最終確認

データの準備

myBridgeのデータは、ExcelかCSVで出してそのまま読み込めます。

  1. myBridgeで名刺帳を開く PC版またはアプリで、登録済みの名刺一覧を開きます。
  2. エクスポートを選ぶ メニューからダウンロード、エクスポート、Excel出力などを選びます。
  3. 形式はそのままでOK Excel（.xlsx）でもCSVでも、変換せずにそのまま読み込めます。
  4. このアプリで読み込む 上の「CSV/Excelを読み込む」から、保存したファイルを選びます。
myBridgeデータの読み込み方
  1. myBridgeで名刺帳を開くPC版またはアプリで名刺一覧を表示します。
  2. エクスポートを選ぶダウンロード、エクスポート、Excel出力などを選びます。
  3. 形式はそのままでOKExcel（.xlsx）でもCSVでも、変換せずに読み込めます。
  4. 読み込むこの画面上部の「CSV/Excelを読み込む」からファイルを選びます。

Google連携（Gmail下書きの一括作成）

未連携です。クライアントIDを設定して「Googleと連携する」を押すと、送信対象タブから全員分のGmail下書きを一括作成できます。名刺データは自分のGmailにしか送られません。

クライアントIDの取り方（初回のみ・10分ほど）
  1. 1. Google Cloudを開くconsole.cloud.google.com にGmailと同じGoogleアカウントでログインし、新しいプロジェクトを作ります（名前は「mybridge-mail」など自由）。
  2. 2. Gmail APIを有効にする「APIとサービス」→「ライブラリ」で Gmail API を検索し、「有効にする」を押します。
  3. 3. 同意画面を作る「APIとサービス」→「OAuth同意画面」で外部を選び、アプリ名と自分のメールを入力。「テストユーザー」に自分のGmailアドレスを追加します。
  4. 4. クライアントIDを作る「認証情報」→「認証情報を作成」→「OAuthクライアントID」。種類は「ウェブアプリケーション」、「承認済みのJavaScript生成元」にこのアプリのURL（例: https://ito-sann.github.io）を追加します。
  5. 5. 貼り付ける作成後に表示される「xxxx.apps.googleusercontent.com」で終わるIDをコピーし、上の欄に貼り付けて「Googleと連携する」を押します。
  6. 6. 警告が出たら初回ログイン時に「このアプリはGoogleで確認されていません」と出たら、「詳細」→「（安全でないページに）移動」で進めます。自分で作ったアプリなので問題ありません。
