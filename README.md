# myBridge Mail Web App

myBridgeから出したCSVを読み込んで、名刺ごとの営業メール文面を作るブラウザアプリです。

## 開き方

[index.html](./index.html) をブラウザで開きます。

## 使い方

1. `CSVを読み込む` でmyBridgeのCSVを読み込む
2. 左の一覧から相手を選ぶ
3. 分類、文体、メモ、メール本文を確認する
4. `Gmailで開く` を押す
5. Gmailの作成画面で最終確認して送信する

`サンプルで試す` でサンプルデータを読み込めます。`編集結果を保存` で編集後のCSVを書き出せます。

## myBridge CSVの準備

1. myBridgeで名刺帳を開く
2. メニューからダウンロード、エクスポート、Excel出力などを選ぶ
3. CSVが選べる場合はCSVで保存する
4. Excel形式の場合は、ExcelやGoogleスプレッドシートで開き、CSV UTF-8として保存する
5. このアプリの `CSVを読み込む` から保存したCSVを選ぶ

CSVに最低限ほしい列は `氏名` と `メールアドレス` です。`会社名`、`部署`、`役職`、`グループ`、`メモ`、`出会った場所`、`紹介者`、`見込み業務` があると文面が作りやすくなります。

## 今の仕様

- データはブラウザ内で処理します。
- CSVは外部サーバーへ送信しません。
- Gmail下書きAPIはまだ使っていません。
- `Gmailで開く` はGmailのメール作成画面を開き、宛先・件名・本文を入れます。
- 分類と文体を選ぶと、文面を再生成できます。
