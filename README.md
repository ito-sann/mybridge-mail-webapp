# myBridge Mail Web App

myBridgeから出したCSVやExcelを読み込んで、名刺ごとの営業メール文面を作るブラウザアプリです。

## 開き方

[index.html](./index.html) をブラウザで開きます。

## 使い方

1. `CSV/Excelを読み込む` でmyBridgeのデータを読み込む（Excelは変換不要でそのまま読めます）
2. 左の一覧から相手を選ぶ
3. 分類、文体、メモ、メール本文を確認する
4. `Gmailで開く` を押す
5. Gmailの作成画面で最終確認して送信する

`サンプルで試す` でサンプルデータを読み込めます。`編集結果を保存` で編集後のCSVを書き出せます。

## myBridgeデータの準備

1. myBridgeで名刺帳を開く
2. メニューからダウンロード、エクスポート、Excel出力などを選ぶ
3. Excel（.xlsx）でもCSVでも、そのままこのアプリの `CSV/Excelを読み込む` から選ぶ

最低限ほしい列は `氏名` と `メールアドレス` です。`会社名`、`部署`、`役職`、`グループ`、`メモ`、`出会った場所`、`紹介者`、`追加日`、`見込み業務` があると文面が作りやすくなります。

## 送信記録の引き継ぎ

下書きを作成した相手・送信済みにした相手・配信停止にした相手は、メールアドレス単位でブラウザに記憶されます。新しいCSVやExcelを読み込み直しても自動で引き継がれるので、同じ人に二重に下書きを作りません。記録は `事務所設定` タブの「送信記録の引き継ぎ」で確認・全消去できます。

## Gmail下書きの一括作成（Google連携）

`送信対象` タブの `Gmailに下書きを一括作成` を押すと、チェックを付けた相手の下書きをGmailにまとめて作れます。送信はされず、Gmailの「下書き」フォルダで確認してから送る運用です。

送る相手は次の方法で選べます。

- 一覧の各行のチェックボックスで個別に選ぶ
- `全員選ぶ` / `全員はずす` でまとめて切り替える
- `追加日が◯日以内の人だけ選ぶ` で、最近追加した名刺だけを一括選択する

追加日は、CSVに `追加日`・`登録日`・`交換日` などの日付列があればそれを使い、なければアプリに取り込んだ日を自動で記録します。

使うには初回だけGoogle CloudでクライアントIDを作る必要があります（無料・10分ほど）。

1. [Google Cloudコンソール](https://console.cloud.google.com/) にGmailと同じアカウントでログインし、新しいプロジェクトを作る（名前は自由）
2. `APIとサービス` → `ライブラリ` で Gmail API を検索して `有効にする`
3. `APIとサービス` → `OAuth同意画面` で外部を選び、アプリ名と自分のメールを入力。テストユーザーに自分のGmailアドレスを追加
4. `認証情報` → `認証情報を作成` → `OAuthクライアントID`。種類は `ウェブアプリケーション`、`承認済みのJavaScript生成元` にこのアプリのURL（例: `https://ito-sann.github.io`）を追加
5. 表示された `xxxx.apps.googleusercontent.com` をコピーし、アプリの `事務所設定` タブに貼り付けて `Googleと連携する` を押す

初回ログインで「このアプリはGoogleで確認されていません」と出たら、`詳細` → `移動` で進めます（自分で作ったアプリなので問題ありません）。

- 安全のため1回の実行は最大50件です。
- 作成済み・送信済みの相手はスキップします。
- 401エラー（ログイン切れ）は自動で再ログインして続行します。

## 今の仕様

- データはブラウザ内で処理します。
- CSVは外部サーバーへ送信しません（Google連携時も、送り先は自分のGmailだけです）。
- `Gmailで開く` はGmailのメール作成画面を開き、宛先・件名・本文を入れます。
- `Gmailに下書きを一括作成` は、Googleログイン後にGmailの下書きをまとめて作成します。
- 分類と文体を選ぶと、文面を再生成できます。
- CSV列名が違っても、列マッピングで `氏名` や `メールアドレス` を指定できます。
- 重複、メールなし、配信停止を診断し、送信対象リストで確認できます。
- 全員分の文面プレビュー、テンプレート保存、事務所情報設定、AI用プロンプトコピーができます。
