# myBridge Mail Web App

myBridgeから出したCSVを読み込んで、名刺ごとの営業メール文面を作るブラウザアプリです。

## 開き方

[index.html](./index.html) をブラウザで開きます。

## 使い方

1. 右上の `+` でmyBridgeのCSVを読み込む
2. 左の一覧から相手を選ぶ
3. 必要なら `出会った場所`、`紹介者`、`見込み業務`、`メモ` を直す
4. 文面を確認する
5. `Gmailで開く` を押す
6. Gmailの作成画面で最終確認して送信する

`S` ボタンでサンプルデータを読み込めます。`↓` ボタンで編集後のCSVを書き出せます。

## 今の仕様

- データはブラウザ内で処理します。
- CSVは外部サーバーへ送信しません。
- Gmail下書きAPIはまだ使っていません。
- `Gmailで開く` はGmailのメール作成画面を開き、宛先・件名・本文を入れます。
